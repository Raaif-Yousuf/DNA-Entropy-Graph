# Keyboard shortcuts and screen readers

You can use the whole app without a mouse.

| Press | What it does |
| --- | --- |
| Ctrl+N | Go to **New run**. |
| Ctrl+O | Choose files to add (on New run). |
| Ctrl+Shift+V | Put the text on your clipboard into the **Paste sequence** box and open it (on New run). Press **Add sequence** to use it. |
| Ctrl+Enter | Run (on New run). |
| F5 | Refresh the list (on Runs). |
| Ctrl+, | Go to **Settings**. |
| Alt+Left | Go back to the page you were on. |
| Esc | Close a question box without choosing. |
| Left or Right arrow | Move along the sequence in the viewer by a quarter of what you see. |
| + and - | Zoom in or out in the viewer. |
| Home or 1 | Show the whole sequence record in the viewer. |
| 2 or 3 | Show 10 kb or 1 kb around the middle of what you see in the viewer. |
| Ctrl+L | Put the cursor in the viewer's position box, ready to type a place such as `chr1:100-500`. |
| Alt, then N, R, C or S | Jump to New run, Runs, Cloud or Settings. Press Alt once and the letters show on the left menu. |

If the clipboard has no text, the app says so and leaves the box as it was: copy your sequence and press Ctrl+Shift+V again.

## Screen readers

On the page that shows a run in progress, the stage (for example "Starting your computer") and the line under it are read out by Narrator each time they change, without you having to move to them.

## High contrast

The app follows the Windows high contrast theme (Settings, Accessibility, Contrast themes). If some text is hard to read in a high contrast theme, tell us which page it was on.

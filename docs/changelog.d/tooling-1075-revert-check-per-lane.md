- **Revert-check has no shared path, and one change gets one fragment (#1075, #1096)**: `scripts/revert_check.py <src files> -- <test command>` saves the fix under the worktree's own git dir, reverts only the named files, expects RED, restores (re-checkout, then `git apply`) and verifies both the diff and the raw file bytes (the old `<scratchpad>/fix.patch` recipe let two workers clobber each other). The orchestrating-agents skill (whose by-hand fallback now uses `git diff --output=`), the git-stash hook message and `docs/dev_commands.md` use it, and the skill notes that `cold-diff-reviewer` has no shell. `check_changelog_fragments.py --base` now fails when an added fragment duplicates another one (same name after stripping one trailing `-r<N>`, whether the other is added or already on the base); a branch stacked on another lane's branch with a different fragment name passes. `docs/ToTest.md` #954 now says how to see the output-folder picker refusal (the picker exists since #1037).

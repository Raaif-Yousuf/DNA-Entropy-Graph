- The billing step is real in the code (issue #51): the app reads whether your project has billing, links the one billing account you have, asks which one when you have several, and when you have none gives a Link billing button that opens Google's billing page for your project. If you may use a billing account but not link projects to it, it offers Copy request for the billing admin (BILLING_NO_PERMISSION). The wizard page that shows it arrives with #99, and production still uses the fake cloud until #56, so nothing in the shipped UI changes yet. Adds Google.Apis.Cloudbilling.v1 (Apache-2.0).
- Review fixes for billing (issues #51 and #539): a permission denial that mentions billing (for example a missing billing role) is now reported as a permission problem, not as "billing is off"; linking with the Billing service off, a project-side permission denial or a billing quota limit no longer tells you to ask the billing admin; and a link Google accepted that left billing off now says so (BILLING_STILL_OFF, action Pick another billing account) instead of sending you back to Link billing.

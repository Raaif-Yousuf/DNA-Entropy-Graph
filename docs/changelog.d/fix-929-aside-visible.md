- A run whose download renamed one of your changed result files aside now says so on its Runs row and at the top of its Results page (when its folder exists), with an Open the output folder button. Covered paths: finished with a warning, finished with an unconfirmed rented-computer end, failed worker with partial files, and a failed download that raised a run failure. The count rides on the run record as a `[kept-aside=N]` mark (`KeptAsideDetail`), so the primary error stays the headline. Not covered, tracked in #1059: a cancel after a rename, a project-wide cloud error or a raw exception after a rename, and a resume after the app closed mid-download (#929).

- feat(worker): a FASTA plus a GFF3 file is now an annotated input: `dna-entropy run -i seq.fasta --gff3 seq.gff3`. The GFF3's genes (`gene`, else `CDS`; discontinuous CDS kept as segments) are matched to FASTA records by name and used for the genes track, gene summary and `.gb`; Prodigal never runs, even with `--genes`. A GFF3 whose names match no record, or paired with a non-FASTA input, is refused with a named action; out-of-range features and malformed lines are dropped with counted notices (#135). The app's auto-pairing and manifest field are follow-ups.
- fix(worker): #135 cold review. The GFF3 sequence name is percent-decoded. An unknown strand (`.` or `?`) stays unstranded instead of becoming `+` (the GenBank writer no longer writes it as `complement(...)`). `Is_circular=true` makes the sequence circular; a feature whose end is past a circular sequence, or two rows sharing an ID across the origin, is kept as a wrapping feature with segments, and on a linear sequence the dropped-feature notice now names both causes. GFF3 `gene` rows sharing an ID are one feature, like `CDS`. Coordinates, the multi-record case and every refusal message are documented and pinned

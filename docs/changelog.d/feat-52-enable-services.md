- Switching on the Google services the app needs is real in the code (issue #52): the app turns on Compute Engine, Cloud Storage and Cloud Quotas in the project in one request, checks every 5 seconds, and only reports success once each service reads ENABLED. The whole call, the request and its retries included, waits at most one 5 minute limit and then reports a timeout. A hiccup while waiting (a busy answer or a hung check) re-reads and never sends the switch-on request a second time. A user who can use the project but is not its Owner gets NOT_PROJECT_OWNER with the action Create project; a "this Google service is off", "billing is off" or organization-policy refusal is reported as that, not as "you are not the Owner". The real preflight chain (project state, billing, Compute API) now has a Google-backed implementation too. The wizard page that shows it arrives with #99, and production still uses the fake cloud until #56, so nothing in the shipped UI changes yet. Adds Google.Apis.ServiceUsage.v1 (Apache-2.0).

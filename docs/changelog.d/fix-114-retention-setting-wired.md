- Cloud results retention (#114): the saved `results_retention_days` setting is now read at each use by the Google storage gateway (`ResultsRetentionSetting`, `GoogleCloudOptions.ResultsRetentionDaysSource`), so a change lengthens the bucket's `jobs/` lifecycle rule on the next run. Before, nothing set the option and the rule stayed at 90 days. Settings gets a "Cloud results" group (`CloudResultsSettingsViewModel`) to choose 7, 30, 90, 180 or 365 days; its copy says the change applies at the next run and that fewer days never shrink a longer bucket. Shortening a longer bucket stays #597/#598.

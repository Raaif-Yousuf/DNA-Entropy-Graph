- tooling: `scripts/land_wt.py --branch B --sha S` lands a committed worktree branch. It checks S is the branch tip, scans changed text files for control bytes, merges origin/main in a throwaway worktree under %TEMP% (docs/ToTest.md is union-resolved, any other conflict refuses with the file list), runs premerge there with `worker\.venv` reached through a junction, then pushes and opens the PR. The junction is removed with `os.rmdir` before `git worktree remove` on every path, so the real venv survives a failed run (#510)

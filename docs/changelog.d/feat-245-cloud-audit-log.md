- feat(app): every call that changes something in the user's Google Cloud project (VM create, reuse, stop, delete; bucket create and object upload; worker identity and IAM writes; Service Usage enable; billing link; project create) is recorded as one JSON line in `logs\cloud-audit.jsonl` under the data root, with time, installation id, job id, operation, resource name, Google request and operation ids (Compute insert), the CloudErrorClassifier outcome and the duration. A decorator per gateway interface (`Audited*Gateway`, wrapped by `CloudAuditRegistration`) keeps `CloudCallPipeline` untouched and audits the fake and the real backend the same way. It never holds a sequence, file name, email or error message, and a failure to write it never reaches the run. Long VM mutations (create, reuse, start, delete) also write a started line before the call, so a killed app leaves evidence; the quota-increase request, disk and job-prefix deletes are audited too. It rotates at 1 MB to `cloud-audit.1.jsonl`, both files ride in the diagnostics zip, and Settings > Diagnostics > Open cloud activity log reveals it (#245)
- fix(app): the cloud audit log's started line and a refused create now carry the Google request id (minted before the call); Storage.EnsureBucket, Storage.DeletePrefix and Iam.EnsureWorkerIdentity also write a started line; rotation is serialised across processes by a named mutex with a short timeout that falls back to append-only; the audit guards are now driven by a reflection scan of every gateway interface; the developer CloudCli is documented as not audited (#245)
- fix(cloud): the audit decorator overrides IComputeGateway.EndVmAsync (merged from #113), so the real gateway's early acceptance report survives the audit wrapper; it is logged as Compute.StopVm or Compute.DeleteVm (#245).
- fix(cloud): the audit log records an outcome of `timeout` when the app's own call deadline fires (GatewayCalls names the caller's token to the audit scope) and `cancelled` only when the caller cancelled; a cut `cloud-audit.jsonl` tail with no newline is dropped whole in the diagnostics zip; the fake no longer carries a no-op request-id read (#245)
- fix(cloud): the reconciler's mutation deadline now reaches the audit as `timeout` (not `cancelled`) through one shared helper, `CloudAuditContext.StartUnderDeadline`, also used by GatewayCalls; a call abandoned at its deadline or by a user cancel is now told to stop at once (it used to run on until it ended by itself); the known race of a user cancel landing after the deadline is documented (#245)

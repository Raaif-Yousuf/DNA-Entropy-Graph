- feat(app): every call that changes something in the user's Google Cloud project (VM create, reuse, stop, delete; bucket create and object upload; worker identity and IAM writes; Service Usage enable; billing link; project create; the quota-increase request; disk and job-prefix deletes) is recorded as one JSON line in `logs\cloud-audit.jsonl` under the data root, with time, installation id, job id, operation, resource name, Google request and operation ids (Compute insert), the CloudErrorClassifier outcome and the duration. The outcome is `timeout` when the app's own call deadline fires and `cancelled` only when the caller cancelled. A decorator per gateway interface (`Audited*Gateway`, wrapped by `CloudAuditRegistration`, covering every gateway interface by a reflection-driven guard) keeps `CloudCallPipeline` untouched and audits the fake and the real backend the same way; the audited `EndVmAsync` keeps the real gateway's early acceptance report and is logged as Compute.StopVm or Compute.DeleteVm. It never holds a sequence, file name, email or error message, and a failure to write it never reaches the run. Long mutations (VM create, reuse, start and delete, Storage.EnsureBucket, Storage.DeletePrefix, Iam.EnsureWorkerIdentity) also write a started line, carrying the Google request id, before the call, so a killed app leaves evidence. It rotates at 1 MB to `cloud-audit.1.jsonl` (serialised across processes by a named mutex with a short timeout that falls back to append-only), both files ride in the diagnostics zip (a cut tail with no newline is dropped whole), and Settings > Diagnostics > Open cloud activity log reveals it. The developer CloudCli is documented as not audited (#245)
- fix(cloud): a call the app gives up on (its deadline passed, or the caller cancelled) is told to stop at once and its later fault is observed, through one shared helper used by the run's gateway calls and the lifecycle reconciler, and every per-call deadline token is made by one `DeadlineSource` (no raw linked source plus `CancelAfter`), so a cancellation callback that throws inside a call can no longer surface out of the user's own Cancel() or end the process from a timer thread (MEASURED 2026-10-29: both happened with the raw linked source); a guard test forbids the raw shape in Core/Cloud (#245)

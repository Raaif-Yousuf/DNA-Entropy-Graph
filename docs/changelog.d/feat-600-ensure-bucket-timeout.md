- Hardening: the results-bucket setup (EnsureBucketAsync, up to about ten requests) now runs under its own 5 minute budget (CloudRunSettings.EnsureBucketTimeout) instead of the 60 s meant for one request, and each single metadata request of it is cut after 30 s per attempt and retried (CloudRetryOptions.AttemptTimeout; uploads and downloads are never capped), so slow retries no longer cut it between creating the bucket and writing its config and a hung request no longer waits out the whole budget. Docs: docs/cloud_design.md sections 11 and 12.

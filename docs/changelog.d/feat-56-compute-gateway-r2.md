- Cloud: a real Compute Engine gateway (`GoogleComputeGateway`) for `IComputeGateway`: create from a `VmSpec` with the six labels, `maxRunDuration`, DELETE termination (anything else is rejected), the spec's worker service account (a spec without one is refused) and the startup script, on the one DLVM image family for CPU and GPU machines, with one `requestId` per create call (reused by every replay of that insert, new for a new call) and the labels on the boot disk; every HTTP request goes through the resilience pipeline on its own (the gateway is not wrapped in `ResilientComputeGateway`), so a transient poll error never replays the insert; polled zone operations classified across every error entry, get, stop and delete (404 means not in that zone), and find or list by label across every zone with partial success requested, failing with a retryable error when a zone is unreachable or a page token repeats instead of returning a partial list. Built into `GoogleCloudGateways.Create(...).Compute`; the app still uses `FakeGcp` until #609. `startup.sh` passes `--gpus all` only when a GPU is expected. (#56)

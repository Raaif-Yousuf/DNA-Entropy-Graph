- Cloud: a real Compute Engine gateway (`GoogleComputeGateway`) for `IComputeGateway`: create from a `VmSpec` with the six labels, `maxRunDuration`, DELETE termination (anything else is rejected), the spec's worker service account (a spec without one is refused) and the startup script, on the one DLVM image family for CPU and GPU machines, with a fresh `requestId` per create; polled zone operations classified across every error entry, get, stop and delete (404 means not in that zone), and find or list by label across every zone, failing with a retryable error when a zone is unreachable instead of returning a partial list. Built into `GoogleCloudGateways.Create(...).Compute`; the app still uses `FakeGcp` until #609. `startup.sh` passes `--gpus all` only when a GPU is expected. (#56)

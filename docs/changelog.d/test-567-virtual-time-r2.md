- test(cloud): every runner and gateway test that asserts a timeout, deadline or delay sum now runs on a virtual clock, so a loaded machine can no longer cut a healthy call (MEASURED 2026-10-03: `A_boot_failure_that_ended_the_VM_before_the_first_look_gets_its_mapped_code` failed in a landing premerge under load on a branch touching no cloud code). The #525 `Clocks` helper is now the shared `RunnerClocks`; `CloudJobRunner{ResumeAndSettle,Outage,Guarantees,Hardening,Heartbeat,Transfer}Tests`, `JobReconcilerTests`, `ResilientStorageTransferTests`, `VmProvisionerTests` and the Google gateway harness use it. A call the test itself scripts to park (a hang, a slow create, a create that never lands) is cut by `FakeGcp.OnCallParked` moving the clock exactly once for that call, after its caller has armed its deadline, so a healthy slow call is never cut. The two gateway delay-sum assertions are now exact (`ShouldBe(10)`, `ShouldBe(20)`) and no test reads a stopwatch. Production code reads time exactly as before (`TimeProvider.System` by default); the only non-test change is the null-in-production `FakeGcp.OnCallParked` hook (#567, refs #566)

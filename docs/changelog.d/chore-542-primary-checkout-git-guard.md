- A new `PreToolUse` hook, `scripts/hooks/block_primary_checkout_git.py` (#542), refuses history-changing git (`checkout`/`switch`, `merge` other than `--ff-only`, `commit`, `reset`, `rebase`, `cherry-pick`, `revert`, `am`, `pull` other than `--ff-only`) when the session directory, a `cd`/`Set-Location`/`Push-Location` prefix, or `git -C` points at the primary checkout, so a worktree-isolated agent cannot strand `main` on a feature branch. Detection is git's own `--git-dir` vs `--git-common-dir`, no path is hard-coded; `git merge --ff-only`, `pull --ff-only`, `fetch`, `worktree ...`, `checkout -- <paths>` and read-only git stay allowed. Registered for both `Bash` and `PowerShell` in `.claude/settings.json`; fails open on any internal error; documented in `scripts/hooks/README.md` with a `--self-test`.

- A new `PreToolUse` hook, `scripts/hooks/block_primary_checkout_git.py` (#542), refuses history-changing git (`checkout`/`switch`, `merge` other than `--ff-only`, `commit`, `reset`, `rebase`, `cherry-pick`, `revert`, `am`, `pull` other than `--ff-only`) when the session directory, a `cd`/`Set-Location`/`Push-Location` prefix, `git -C`, `--git-dir` or `--work-tree` points at the primary checkout, so a worktree-isolated agent cannot strand `main` on a feature branch. Detection is git's own `--git-dir` vs `--git-common-dir` (cached per directory, 3 second timeout that fails open), no path is hard-coded. Allowed: `git merge --ff-only`, `pull --ff-only`, `fetch`, `worktree ...`, path restores (`checkout -- <paths>`, `checkout .`, `reset -- <paths>`), read-only git, and recovery onto `main` only (`switch main`, `checkout main`, `checkout -B main origin/main`, `switch -C main origin/main`). Only those exact shapes (plus `-f`/`-q`) change branch; glued or abbreviated flags such as `-bfeat` or `--det` are refused, and `--ff-only` counts only when it is the last of `--ff-only`/`--ff`/`--no-ff`. It looks through `bash -lc`, `cmd /c`, `pwsh -Co...`, `env`, `time`, `nohup`, `command`, `then`/`do`/`{` and `GIT_DIR`/`GIT_WORK_TREE` assignments; heredoc bodies are data except for a shell (here-strings, quotes, `$((1<<N))` and an unterminated heredoc hide nothing). Total git time is capped at 5 seconds per invocation, then it allows. Registered for both `Bash` and `PowerShell` in `.claude/settings.json`; fails open on any internal error, including a failed import of its sibling module (which would otherwise make `run_hook.py` deny every command); documented in `scripts/hooks/README.md` with a `--self-test`. Known limits: `gh pr checkout`, `update-ref`, `symbolic-ref` and git run inside a script are not seen.

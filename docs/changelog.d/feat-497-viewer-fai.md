- The embedded viewer opens a sequence file over 50 MB (up to 1 GB) by generating a samtools-format `.fai` (#497): `FastaIndexWriter` streams the FASTA, the index is kept in the app's own `fai` folder (never beside the user's file or inside a run folder, Hard Rule 14) and served as `https://fai.deg/`, and igv.js loads the reference with `indexed:true`. An index that cannot be built shows its own message (`IndexFailed`).

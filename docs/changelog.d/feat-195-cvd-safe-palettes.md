- Colourblind-safe track colours (#195): one palette definition (`Core/Palettes`, Okabe-Ito default plus a high-contrast option) now colours the overview chart, the Runs sparkline, the PNG export and the igv.js viewer (tracks and seam markers, passed through the bridge instead of spelled in JavaScript). A `PaletteValidator` test checks every palette against both backgrounds and under deuteranopia, protanopia and tritanopia (Machado matrices, CIEDE2000), including the colours as the viewer's dark-mode filter turns them. Settings > Appearance has a "Colours of the entropy lines" choice, saved as `TrackPalette` and read each time something draws.

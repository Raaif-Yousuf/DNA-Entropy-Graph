- Fixed a race in the test double `FakeGcp` (#875): a stop was a read-then-write of the VM row, so a delete landing between them was overwritten and the deleted VM came back as STOPPED, which made `A_delete_asked_while_a_stop_is_in_flight_is_sent_and_the_row_names_the_delete` fail once in CI. The stop is now a compare-and-swap, as real Compute deletes the instance when a delete is issued during a stop. No product code changed.
- Every change to a FakeGcp VM row (stop, start/reuse, relabel, boot, stopping and preempt polls) now goes through one compare-and-swap helper, UpdateVm, that gives up when the row was deleted; a test fails if a bare `_vms[key] =` assignment appears outside the two creates (#875).

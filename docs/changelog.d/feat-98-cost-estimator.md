- The New run page shows a pre-run cost and time estimate for the selected file ("Estimate: about $0.13, about 9 minutes", or a range when there are no earlier runs on this PC), worked out from a price list that ships in the app (`Assets\pricing.json`, asserted present in the CI publish output) and this PC's run history. History gives the start-up time and your file's own analysis time is added, so a 5 kb and a 5 Mb file are never priced the same; the disk is priced at the run's own boot disk size, and a second line says what that disk costs per day while the computer sits stopped after the run. A kind of computer with no price (the H100 tier) or no Spot price says the estimate is not available for it yet, an unreadable price list says to reinstall the app, and a new check clears the old estimate (#98, partial: the Billing Catalog refresh is #214, the live ticker #217, the actual cost #557).

- worker: the model weights cache is wired in (#75). For an Evo job the runner moves to `restoring-cache`, restores `cache/models/<id>/` from the bucket root into the Hugging Face cache before the predictor loads, and after a load that downloaded mirrors the new files back, both best effort (a failure is a progress notice, never a failed job). `_COMPLETE.json` is written last and checked, with sizes, on restore, so an interrupted mirror is never restored. The cache is at the bucket root, not under `jobs/<id>/`. `startup.sh` now mounts a uid-10001-writable cache and sets `HF_HOME`. The mirror runs only when the HF cache was empty before the load, honours cancel between files, and a restore rolls back on any error and refuses unsafe marker paths.

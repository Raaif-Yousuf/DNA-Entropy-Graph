- Portable mode (#144, #805): an empty `portable.flag` beside the program (beside `Update.exe` in a Velopack install, so updates keep it) makes the app keep all its state in a `data` folder beside it instead of `%LOCALAPPDATA%`, and results in an `outputs` folder beside that. Paths on the stick are stored relative so a new drive letter still opens results, the database avoids WAL, and Open with is refused so no registry entry points at the stick. `--profile` and `DEG_DATA_DIR` still win. Sign-in does not travel between PCs (DPAPI); the new PC asks to sign in again.

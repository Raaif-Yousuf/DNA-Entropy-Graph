- feat(worker): every run now also writes `<name>.entropy.smooth51.bedgraph` (or `.wig`), a 51-base rolling mean of the entropy track, beside the raw track, which stays primary. The window list is the new `analysis.smoothingWindows` manifest option (default `[51]`, odd numbers only) and `--smoothing-window` on the CLI; a window of 1 is the raw track bit for bit. On a linear molecule the window shrinks at the ends; on a circular one it wraps the origin. New `smoothed` output name and `--no-smoothed`; the viewer toggle is tracked in #552 (#126)

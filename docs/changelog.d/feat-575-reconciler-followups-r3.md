- The diagnostics log is capped at 1 MB with one rotated copy (a rotation that cannot move the file, because the copy is held open or read-only, appends anyway up to twice the cap and then drops lines, so the log cannot grow without bound; every control character and the Unicode line separators in a field become a space, so one event is one line) and no longer lets any non-fatal exception out; a failing lifecycle step no longer orphans the reattached runs (the pass logs it and still hands the runs back, so `WhenIdleAsync` waits for them); the reconnect observer no longer nests a wait per reconnect while a long run goes on (#575).

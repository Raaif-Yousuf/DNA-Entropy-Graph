- feat(app): the Results page header and each Runs row show the run's estimated cost: the figure the spend ledger booked for that run, and nothing else (#100, #557). The run's ledger entry is the only record of a run's cost: it is first-write-wins, so two writers, a later copy of the run, or a later finish time never change what a run shows, and the run pages always match the month total. Spot-aware wording (a Spot run on a machine with no Spot price reads as an ordinary estimate; the wording follows the current price list, a documented limit), "no cloud cost" for This PC runs, no line for a run that never had a VM, and no line when the ledger cannot be read. The Runs page shows a run's cost as soon as the run ends while the page is open, and stops listening once you have left it; the app resolves its UI dispatcher on the UI thread at launch. Nothing is written onto the run row; `RunRecord.ActualCostUsd` is documented as reserved and unused. Run targets are the shared `RunTargets` constants, compared case-insensitively.

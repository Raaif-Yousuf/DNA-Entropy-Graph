- Settings: Share settings group. Export settings saves the allowlisted defaults and your presets to a versioned JSON file; Import settings previews every change (current value, new value) and writes only on Apply. Secrets, ids, window position, program paths and developer switches never travel, an unknown future version is refused with an action, and a guard fails when a settings key is neither exported nor excluded (#242).
- Settings import: a file with a repeated key is reported as unreadable instead of crashing, and the preset count in the preview is worked out against this PC's own presets (#242).

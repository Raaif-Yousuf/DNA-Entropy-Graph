- feat(cloud): the app can now read a project's real GPU quota, step one of issue #88 (the quota request flow and the ineligible-account guidance are its sub-issues). `GoogleQuotaGateway` reads each region's quotas with `regions.list` (NVIDIA GPU metrics, CPUS, SSD_TOTAL_GB, paged) and the project-wide GPUS_ALL_REGIONS with `projects.get`, and `GoogleCloudGateways.Create(...).Quota` returns it. `IQuotaGateway.ReadQuotaAsync` returns a table whose `GpuState` is unknown, none or available: a global cap of 0 overrides a regional 1, and a read that failed (403, 500, a stuck page token, a missing cap) is unknown, never zero; `GetGpuQuotaAsync` throws on an unreadable quota instead of returning 0. `FakeGcp` gains the same table (`WithQuotaReadFailing`). Production still uses `FakeGcp` until #609. Docs: `docs/cloud_design.md` section 6.1, one `docs/ToTest.md` row.

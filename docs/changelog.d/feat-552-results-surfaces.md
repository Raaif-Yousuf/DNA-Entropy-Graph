- app: Results page and viewer surfaces for the worker's new outputs (#552). Results lists every `<name>.genes.tsv` as a table you sort by clicking a heading (first click lowest first, again to reverse; numbers sort as numbers, ties keep the file's order; the first 500 rows are drawn and a note names the file for the rest); the file is read by `Core/Tracks/GeneTable.cs` and an unreadable one gets a message naming Open in the file list. The embedded viewer draws `<name>.regions.bed` (else `.regions.gff3`) as an "Entropy regions" feature track, and lists each `<name>.entropy.smooth<W>.bedgraph` as a tick box (off at first so the raw track stays primary) that adds or removes a 0 to 2 bit track through a new `track` command in `bridge.js`. `RunOptions` gains `RegionThreshold`, `RegionMinLength`, `RegionMergeGap` and `SmoothingWindows`, which `WorkerManifestBuilder` sends as `analysis.regionThreshold`, `regionMinLength`, `regionMergeGap` and `smoothingWindows` only when `regions` or `smoothed` is chosen (no settings screen for them yet).

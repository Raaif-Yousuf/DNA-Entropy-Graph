- Fixed #957: the LocalJobRunner run-cap test no longer depends on machine load. The virtual clock now moves in lockstep with the runner (it only advances once the runner has re-armed its poll timer), in 20 s steps, so a starved runner thread cannot let the clock run ahead and end the run Stalled instead of TimedOut. The cap assertion now has an upper bound, test heartbeats are written atomically, and the no-heartbeat test asserts the 60-second message. The test still fails when the cap is disabled or the margin is 50 minutes.

- fix(worker): a third-party exception's free-text `.code` could reach `result.json` `error.code` and the Save diagnostics zip. The worker now writes only codes from its own registry (anything else is `WORKER_CRASH`), and the diagnostics bundle keeps an `error.code` only when it is a known worker code, redacting a number, object or unknown text. The original `.code` is kept for the developer in `error.detail` as `original code: <ascii repr, 80 chars>`, never in `error.code`; the diagnostics scrub list skips a plain-word rejected code such as `job` (#613).

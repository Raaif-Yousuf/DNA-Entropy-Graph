- **Land a lane as a PR without sweeping in other lanes (#445)**: `scripts/land_pr.py` does branch, explicit-path commit, push, PR, wait-for-green, merge and return-to-main in one call. It refuses on a directory path, an unchanged path, foreign staged content, an existing branch, a missing premerge stamp, or zero checks (unless `--allow-no-checks`); stages selected hunks by index (`--list-hunks`, `--hunks FILE=0,2`) with the patch built and applied as bytes (Windows text mode corrupts non-ASCII context); and returns the tree with `git checkout -B main origin/main`, because `git switch main` refuses while a landed file is still modified for another issue. Tests use a bare remote, a clone and a stub `gh`; mutation checks on both traps went red.

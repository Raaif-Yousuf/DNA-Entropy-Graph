- Corporate proxy support (issue #239): Settings > Advanced > Network proxy chooses between the Windows settings (the default, including automatic proxy scripts and the Windows sign-in for NTLM or Kerberos proxies), one typed `host:port` proxy with an optional DPAPI-encrypted user name and password, or no proxy. One `ProxyPolicy` is applied to the sign-in, every Google gateway and the Velopack update check, and a change reaches the next request with no restart. A proxy that refuses the connection (407 or a refused tunnel) now says so as `proxy_blocked` / `SIGNIN_PROXY` and an untrusted network certificate as `network_certificate` / `SIGNIN_CERTIFICATE`, each with one action, instead of "check your internet connection", and neither is retried. The diagnostics zip records only the proxy mode.

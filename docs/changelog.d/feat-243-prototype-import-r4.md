- Earlier-version (prototype) runs no longer show the "Found in your cloud results, made on computer ?" badge, and runs found in the cloud no longer show the earlier-version delete hint (told apart by `RunRecord.IsPrototypeImport` / `IsCloudImport`); removing a prototype run no longer writes the bucket-dismissals setting. The first-launch tour now waits for the earlier-version question to be answered instead of opening over it. (#243) A finished earlier-version row's Delete cloud copy tooltip now says it has no cloud copy and points to Open (it used to point to Run again, which is off for those rows). The tour start no longer depends on call order and starts however the offers ended. The startup offers can no longer crash the first load: an unreadable settings file (not only a locked one) now means "ask again next launch", and the shell never lets an offers error escape; the offers run on the app's own lifetime, so a caller's cancelled token only ends that caller's wait.

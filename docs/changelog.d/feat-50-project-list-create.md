- Setting up a Google Cloud project is real in the code (issue #50): the app lists the projects an account can see (the ones it made first), makes a new `dna-entropy-<random>` project with one click, waits for Google to finish, and reports the project limit (PROJECT_QUOTA, action Pick an existing project) and an organization block (ORG_POLICY_BLOCK, action Copy message for IT) by name. The wizard page that calls it arrives with #99, and production still uses the fake cloud until #56, so nothing in the shipped UI changes yet. The real Google calls use the REST client packages Google.Apis.CloudResourceManager.v3 (Apache-2.0); Google.Apis.Auth moved to 1.77.0 with them.

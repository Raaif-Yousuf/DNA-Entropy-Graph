- Worker (#41): `result.json` is now the last object written to the store. - Worker/startup script (#464): a Keep-alive run is no longer stopped the moment the job ends. With `keepAliveMinutes > 0` the worker makes no Compute call and `startup.sh` holds the VM for the window (capped to end 10 minutes before `maxRunDuration`), then applies `afterKeepAlive`; no window still stops at once. New `keep_plan`/`keep_hold` tests run the real script text in bash.
- Worker (#468): `validate_sequence` no longer case-folds non-ASCII letters into IUPAC codes (sharp s became SS, long s became S, lengthening the sequence). Only a-z is uppercased; any other non-ASCII letter is refused as an invalid character, named by code point (U+00DF) at its true position.

New `worker/src/dna_entropy/worker/gpu.py` and `test_worker_gpu.py` (nvidia-smi injected; the real-VM check is a ToTest item).

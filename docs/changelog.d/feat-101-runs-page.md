- feat(app): the Runs page (#101). The Runs item in the menu now opens the real history: runs grouped by day (newest first), a search box (name, input file name, id, notes) and a status filter, and per run Open, Run again (same recorded settings, the app's own copy of the input), Download again (restores the results from your cloud storage until the retention window ends, rechecking each file's size and checksum), Delete cloud copy, Delete files on this PC and Remove from list. Every deletion asks first; deleting files only ever removes the run's own folder inside its output folder and never the input copy, and deleting the cloud copy only ever targets that job's own prefix. Delete cloud copy reports "not connected" until the cloud lane adds object deletion to the storage gateway; sparklines on the rows are #118. The confirm dialog is now a real dialog (it used to answer "no" to everything). `.gitignore` no longer hides source folders named `Runs`.
- fix(app): Runs page review follow-ups (#101): a run still going can no longer have its folder deleted from the list; every row action that fails (a file open elsewhere, a network error, a run that cannot start) shows a message naming one action instead of failing silently; Download again keeps files already in the folder, restores partial results of a run that did not finish with a clear message, and accepts a folder path with a trailing slash; Delete cloud copy is greyed out with an explanation until object deletion lands (#534); the confirm dialog queues one at a time, honours cancellation and no longer leaves a caller hanging on an error; the duplicate page title is gone.

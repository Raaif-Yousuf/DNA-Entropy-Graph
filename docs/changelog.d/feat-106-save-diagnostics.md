- Settings > Diagnostics > Save diagnostics (#106) writes a support zip with worker and run logs, run history (ids, states, error codes), per-run status/progress/result files (allowlisted keys only), a settings subset, versions and the installation id, and never a sequence, input or contig name, path, output file, email or credential. The Settings page and its nav route are new (#104 extends them), which makes the "Choose Save diagnostics in Settings" error strings true. Redaction covers any sequence layout (IUPAC, RNA, GenBank ORIGIN, wrapped, split), any Windows path, and tokens; a separate, stricter final scan refuses to write the zip and names the entry (it also checks the user's own identifiers, any email and any drive or UNC path, in entry content and entry names); copied logs get neutral names (`log-01.log`) and the README text comes from `Resources.resw`; unparseable JSON is left out with a note; a refused, cancelled (even before it started) or failed save removes the empty file the picker made and never throws into the UI. App logs are not included until #164 writes them. See `threat_model.md` section 5b.

- Slow-run UI (#675): RunStallCoordinator is now the runner's OnNotice and OnStall in production. A stage past 75 percent of its deadline shows a yellow "taking longer than usual" line on the run page; a stall opens a Stop / Delete / Keep waiting dialog (IChoiceDialogService, a three-button ContentDialog on the main window); a dialog that cannot be shown answers Keep waiting, never a deletion. The log-only defaults stay for runners built without a UI.

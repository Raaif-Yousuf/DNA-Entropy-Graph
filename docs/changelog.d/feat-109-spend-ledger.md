- feat(app): monthly spend ledger and spending cap (#109). When a run row first reaches an ended phase (any writer: runner, reconciler, cleanup) a `vm_runtime` CostLedger row is written once per run, priced from the run's start to end, the machine's rate (Spot rate for Spot) and its boot disk; the run row also gets VmSeconds and EstimatedCostUsd. Month-to-date is summed over the local calendar month. Settings > Spending adds a warning cap and a hard stop; the New run page shows a cap card (warning allows Run), and with the hard stop on the engine refuses the run before anything is created with the new `spend_cap` error (action: Open Settings). All figures are estimates; #557 (actual cost) and #150 (CSV export) can read the same ledger. No migration was needed.

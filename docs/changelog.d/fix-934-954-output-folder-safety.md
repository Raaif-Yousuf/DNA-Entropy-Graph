- Every run output folder the app creates now holds a `.dna-entropy-run` marker naming its job (#934). Delete files on this PC requires the marker: a folder of another run is refused (Open folder button), a folder with no marker (an older run, or one named by a damaged history row) is deleted only after one question showing its full path, and the local-run reconcile copies results only into a marked folder. A run saved straight to a drive (`D:\`) says why Delete and Download again are not offered, with an Open folder button, and the output-folder check refuses a whole drive (#954). Cloud runs get their marker once `RunTransfer` passes the job id to `CreateUnique` (reported to the cloud lane).

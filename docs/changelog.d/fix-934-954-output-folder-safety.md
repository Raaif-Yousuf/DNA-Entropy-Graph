DECISION (agent-made, reversible): the children of Documents, Desktop and the like are not protected, because older runs live there; they get the one question. The link and marker state is re-checked immediately before the first file is deleted, and each folder is re-checked for a link immediately before the files in it are deleted, so a swap between the plan and the delete stops it. A refusal shown without a dialog (or whose dialog could not be shown) is a toast that names the row's Open button and then Open folder on the page it opens. An empty folder holding another run's marker is never removed by a failed run's cleanup. A run saved straight to a drive (`D:\`) says why Delete and Download again are not offered, and the output-folder check refuses a whole drive (#954).

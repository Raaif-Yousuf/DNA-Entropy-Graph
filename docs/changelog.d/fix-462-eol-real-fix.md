- The real fix for #462 (`dotnet format` ENDOFLINE on a Windows checkout). MEASURED 2026-10-15: in a fresh worktree `dotnet format DnaEntropyGraph.sln --verify-no-changes` exits 0, because `.gitattributes` (`* text=auto eol=lf`) wins over `core.autocrlf=true`; the noise only exists in a stale CRLF tree, so the earlier THEORY (autocrlf converts on checkout) was wrong. New `scripts/fix_eol.py` (`--check` to list) rewrites exactly the tracked files that git holds as LF but the tree holds as CRLF/mixed; premerge now forgives ENDOFLINE (KNOWN) only when such a stale file exists and names the script, so ENDOFLINE in an LF tree is a real FAIL and the format gate is no longer silently blind.

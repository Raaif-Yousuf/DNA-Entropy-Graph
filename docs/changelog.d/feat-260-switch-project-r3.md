A run row with no project is skipped by the bucket memory instead of throwing after the run ended. The reconciler now remembers the bucket for runs it fails in place or cancels, not only for runs it resumes. The Settings project card follows account changes while open (and detaches when the page is left) and observes every refresh failure.
